# Nguồn ý tưởng và giấy phép

Mã nguồn skill này được viết mới hoàn toàn. Các ý tưởng tham khảo từ những skill cộng đồng sau, nhưng không chép mã:

| Ý tưởng | Lấy từ |
|---|---|
| Phân tích nội dung: mục tiêu học tập, phân tầng độ phức tạp, chép nguyên văn số liệu và định nghĩa | JimLiu/baoyu-skills (`baoyu-infographic`) |
| Tách "nói gì" (blueprint) khỏi "vẽ thế nào"; sửa đúng chỗ hỏng thay vì viết lại | yansfil/grab-skills (`sketchnote`) |
| Chắt lọc ý, giới hạn số thẻ, gộp hoặc bỏ thay vì thu nhỏ chữ; soát lại từng chữ có dấu; adapter cho GPT Image và Gemini | egany/sketchnote-creator |
| "Đọc, đừng hỏi"; chọn hình theo quan hệ giữa các ý | Yuzc-001/hand-drawn-note-generator |
| Dựng bằng HTML rồi chụp thành PNG, đổi giao diện bằng biến CSS | aizzaku/aiz-infographic |
